remoteMe

Selbst gehostete Fernwartung. Bildschirm sehen, Maus und Tastatur bedienen, Dateien per Drag & Drop hin- und herschieben – direkt im Browser, für Windows, Linux und macOS.

Auf GitHub ansehen Bedienung Entwicklerdoku

Funktionen

Fühlt sich an wie davor sitzen

Live-Bild des Zielrechners, Maus, Tastatur, Mausrad, Vollbild, mehrere Monitore.

Drag & Drop für Dateien

Dateien aufs Fenster ziehen zum Hochladen; aus dem Dateipanel auf den eigenen Desktop ziehen zum Herunterladen. Ordner als ZIP.

Zwischenablage

Text wird in beide Richtungen übertragen, auch Strg+V.

Keine Portfreigaben

Agent und Browser verbinden sich ausgehend zu deinem Server – funktioniert hinter jeder Firewall.

Sichere Kopplung

Benutzer anlegen, Agent installieren, Benutzernamen eingeben, Code bestätigen. Erst dann ist der Rechner erreichbar.

Windows · Linux · macOS

Ein Go-Projekt, ein Agent je Betriebssystem, Server als einzelne Datei.

So funktioniert es

Browser (Viewer) <──HTTPS/WSS──> Relay-Server <──WSS── Agent (Zielrechner)
  1. Benutzer anlegen: Server im Browser öffnen und registrieren.
  2. Agent installieren: am Zielrechner starten, Server und den Benutzer eingeben, der zugreifen darf. Der Agent zeigt einen 6-stelligen Code.
  3. Freigeben: Code im Browser beim neuen Gerät eingeben – fertig. Ab jetzt reicht ein Klick auf „Verbinden".

Schnellstart

git clone https://github.com/fmatsch/remoteMe.git
cd remoteMe
go run ./cmd/server -addr 127.0.0.1:8080 -data data.json
# zweites Terminal
go run ./cmd/agent -server http://127.0.0.1:8080

Dann http://127.0.0.1:8080 öffnen. Für den Einsatz im Internet den Server hinter TLS (z. B. Caddy) betreiben.
